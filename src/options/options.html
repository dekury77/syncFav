미연결

1. Google Drive 연결 (OAuth 2.0)

Ego Lite처럼 Google 계정 로그인이 없는 브라우저에서도 동작하도록 표준 OAuth 2.0 launchWebAuthFlow를 사용합니다.

Google Cloud Console OAuth Client ID 발급 가이드 (최초 1회, 약 3분)
  1. Google Cloud Console에서 새 프로젝트를 생성합니다 (예: SyncFav).
  2. API 및 서비스 > 라이브러리에서 Google Drive API를 검색해 사용을 클릭합니다.
  3. OAuth 동의 화면에서 외부(External)로 앱을 만들고, 테스트 사용자에 본인 Gmail 주소를 추가합니다.
  4. 사용자 인증 정보 > 사용자 인증 정보 만들기 > OAuth 클라이언트 ID에서 애플리케이션 유형을 웹 애플리케이션으로 선택합니다.
  5. 승인된 리디렉션 URI에 아래 표시된 Redirect URI를 복사해 붙여넣습니다. (다른 컴퓨터에 설치할 때 확장프로그램 ID가 다르면 해당 컴퓨터의 URI도 함께 추가하세요)
  6. 생성된 클라이언트 ID와 클라이언트 보안 비밀번호(권장)를 아래 입력란에 넣고 연결합니다.
