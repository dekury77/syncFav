Google Drive 연결

Ego Lite, Chrome 등 계정 동기화가 없는 Chromium 브라우저 간 OAuth 2.0으로 안전하게 연결합니다.

manifest 고정 키 덕분에 집컴·회사컴·Chrome 어디서나 동일한 URI가 유지됩니다.
Google Cloud Console OAuth 설정 가이드 보기
  1. Google Cloud Console에서 프로젝트를 만들고 Google Drive API를 사용 설정합니다.
  2. OAuth 동의 화면에서 외부 앱을 구성하고 테스트 사용자에 본인 Gmail을 추가합니다.
  3. 웹 애플리케이션 OAuth 클라이언트를 만들고 승인된 리디렉션 URI에 위 Redirect URI를 추가합니다.
  4. 발급된 Client ID와 Client Secret을 입력한 뒤 연결 버튼을 누릅니다.
