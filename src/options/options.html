Google Drive Connection

Connect securely via OAuth 2.0 across Chromium browsers even without built-in browser account sync.

Using your own Google Cloud OAuth app (Advanced)
Register this URI only if you are connecting your own custom Google Cloud OAuth app.
  1. Create a project in Google Cloud Console and enable the Google Drive API.
  2. Configure the OAuth consent screen as External and add your Gmail as a test user.
  3. Create a Web Application OAuth client and add the Redirect URI above.
  4. Enter your Client ID and Client Secret, then click Connect Google Drive.
